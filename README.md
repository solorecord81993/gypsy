# ไพ่ยิปซีตอบคำถาม

เว็บแอปเปิดไพ่ Rider–Waite–Smith 78 ใบ สำหรับคำถามหนึ่งเรื่อง เลือกเปิดได้ 1, 3, 5 หรือ 10 ใบ และอ่านคำทำนายได้ทั้งภาพรวมและทีละใบ

## คุณสมบัติ

- สุ่มไพ่แบบไม่ซ้ำ พร้อมไพ่ตั้งตรงและกลับหัว
- รูปแบบการวางไพ่แตกต่างตามจำนวนไพ่
- คำทำนายปรับบริบทตามคำถามด้านความรัก งาน การเงิน สุขภาพ และการตัดสินใจ
- ทำงานในเบราว์เซอร์โดยไม่ต้องสมัครหรือส่งคำถามออกจากอุปกรณ์
- รองรับมือถือ แท็บเล็ต และเดสก์ท็อป

ภาพไพ่ Rider–Waite–Smith ต้นฉบับ ค.ศ. 1909 เป็นสาธารณสมบัติ และเรียกใช้จาก Wikimedia Commons
